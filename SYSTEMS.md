# Oroboro systems index

**Speculative in-silico modeling only. No clinical, medical, biological, engineering, flight or operational claims.** Every number in these repositories is a model output, not a measurement. Levy weights and Oasis scores are bookkeeping and routing signals, not energies or truth tests.

This page links every Oroboro system to the code that implements it, plus the studies, reports and related repositories. Every link below was checked against `main` on 27 November 2026. Line anchors (`#L…`) point to the class or function definition at that date.

Creator: Caitlyn Randels (Caitlyn Connor Randels).

## How the pieces fit (conjunctive pipeline)

Genesis → state reduction → **Oasis** salience gate → **PrinciplesGate / AdaptOrDie** → **NaCl polarity mesh** consensus → **Dictator** → **Transcriber** → **Levy** ledger → **Nexus** register / recombine → **damped delta reconciliation** → homeostasis → back to Genesis. The full write-up is in [research/PIPELINE.md](https://github.com/caitlynrandels-del/Oroboro/blob/main/research/PIPELINE.md).
