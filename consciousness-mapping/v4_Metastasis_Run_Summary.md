# v4 Metastasis Simulation Run Summary

**Completed 26 November 2026**

Architecture-testbed note for the Oroboro relational simulation framework applied to a post-dissemination cascade.

## Summary

The v4 run (3.82 million discrete-time stochastic simulations) completed with zero consistency failures. The absorbent intermediary (sponge) was treated as a standard on/off toggle alongside other optional layers. Public-data fits, the operational update sequence, and precision-targeted adaptive experiments were all active.

Key internal results matched prior calibrated runs exactly on dormant fraction and reproduced the directional effects of the sponge (reduced overt colonization, increased residual hidden pool, delayed first lesion, modest reduction in full elimination). New observations included a small sponge-size effect under load and a degradation of public-data fit when all optional layers (especially tissue-scaffold) were active.

Speculative modeling / architecture testbed only. No clinical claims.

See the metastatic-cascade-analysis repository for the full paper and model code.
